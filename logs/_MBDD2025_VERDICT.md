## 二、修正后的段划分（关键）

**旧切分**（按错误的 `2,561,278,781`）：
```

seg7  = [7*320,159,847, 2,561,278,780]           ← ★ 上界越界！
```

## 八、★ 附：本次下载的方法论要点

| 要点 | 说明 |
|---|---|
| **取签名 URL（无需凭据）** | `curl -sS -L -A Mozilla/5.0 -D - -o /dev/null -r 0-1023 <kaggle download url>`，从响应头取 `location` |
| **实测真实大小** | 对签名 URL 二分探测 Range，`416` = 越界 |
| **切分要按真实大小** | 否则末段上界越界 → 永远下不完 |
| **串行下载** | 实测 ~3.8 MB/s，远快于 8 段并行的 ~27 KB/s |
| **不能续传** | `curl -r a-b` 输出到已有文件是**覆盖**不是追加；`-r` 与 `-C -` 混用无效 |
| **段要先写 `.part` 再 rename** | 避免半成品污染 |
