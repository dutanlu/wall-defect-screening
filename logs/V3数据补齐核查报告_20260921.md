## 5. 去重与泄漏自检

### 5.1 组装去重（`01_data/audit/v3_build_report.json`）

```
合并后可用配对            2854
L1 完全重复(MD5)          5 组 / 冗余 5 张     -> 2849
L2 近似重复(dHash<=3)     1 组 / 冗余 1 张     -> 2848
最终保留                  2848 张唯一图
落盘失败(n_write_fail)    0
```

各源入选：`greybrick-yolo 649`、`hrcds_yolo_exposed_rebar 462`、`rebar_structural 25`、`urban_yolo_rust_delam 1712`。

> L2 近似去重是**这次的关键**。历史上把 mAP@0.5 抬到 0.971 的元凶就是同一面墙的多张近似图被随机劈到 train/val 两侧；`urban` 数据里同一面墙常有连拍，不做 L2 就会形成新的、看不见的泄漏。

### 5.2 划分泄漏自检（`04_results/eval/split_report.json`）

9 项跨集交集**全部为 0**：

```
OK train-val  names / md5 / dhash  各 0
OK train-test names / md5 / dhash  各 0
OK val-test   names / md5 / dhash  各 0
leak_free = true
```

`train.py` 在开训前**又独立复检了一次**文件名交集，同样全 0。
