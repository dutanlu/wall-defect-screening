- **赛题**：第六届萌新种子杯 · **视觉赛道 · 创新题**（北京建筑大学 · 光启 Ray-space 工作室）
- **参赛形式**：**单人**

- **时间窗口**：2026-09-20 → 2026-10-08
- **作品定位**（答辩主论点，别丢）：**不是"更准的裂缝检测器"，而是一个"知道自己什么时候
  不可靠"的外墙缺陷筛查系统**。核心洞见：在房屋安全场景里，把远处的小裂缝误判为"安全"
  的代价，远高于漏检。

### 1.2 技术链路（三层串联）

```
YOLO11s（定位+分类 7 类）
   ↓
OpenCV 几何量化（形态学分割 → 宽度/长度/面积，换算到毫米）
   ↓
规则分级（GB 50010-2010 裂缝限值 + JGJ 125-2016 危险点 → A/B/C/D/U 五档）
```

**系统的一等公民是"可判读性"**：

```
GSD（地面采样距离）= 画面水平覆盖宽度 ÷ 图像水平像素数
可判读性 = 目标实际尺寸 ÷ GSD        （经验门槛：≥ 3 像素才可靠）
```

不可判读时**拒绝给出定量结论**，并把拒答**传染到输出层**（该类全部定量结论作废，
风险等级输出 `U` 而非 `A`）。

### 6.2 已踩过的坑（复核时最易重犯）

1. **含反引号的长文本用 `bash -c "python -c '...'"` 内联写** ⇒ 反引号被当命令替换，
   **静默吞内容，exit 0 但文件已损坏**。⇒ 一律 Write 落文件再执行。
2. **PowerShell 的 stdout 不回传给模型** ⇒ 先 `Set-Content` 写文件再 Read。
3. **`Path.read_text()` 量行尾会假报**（universal newline）⇒ 只用 `read_bytes()` 的
   `count(b"\r")` / `count(b"\n")`。
4. **写回 CRLF 前不归一化** ⇒ 产生 `\r\r\n`（双 CR）污染（本工程 2026-09-28 实际发生过，
   README 688 处 / `07_report/README.md` 565 处 / `项目介绍书.md` 9 处）。
   ⇒ 必须 `re.sub(rb'\r+\n', b'\n', b)` 归一化再展开，并断言 `CR == LF == CRLF` 且 `\r\r\n == 0`。
   **★ 光看 `CR == LF` 看不出来，必须显式数 `\r\r\n`。**
5. **用 `head` 截断"完整性检查"** ⇒ 会**静默漏掉**真正的命中（本次审计实际踩到：
   搜 `0.71093` 时被标注文件占满前 12 行，差点误判"该数字无产物支撑"）。
   ⇒ 完整性检查**不许 `head`**。
6. **定量化脚本 stdout 用 `grep` 管道** ⇒ 见 §6.1 最后几行。
7. **`cv2.imread/imwrite` 遇中文路径静默失败** ⇒ 本工程统一走 `common.imread_u/imwrite_u`。
8. **`except Exception: x = None`** 会把签名错误伪装成"数据缺失" ⇒ 比崩溃更坏。
9. **训练是静默失败**：判断在不在跑**看落盘**（`args.yaml`/`results.csv`），
   **不看退出码**。

## §10 术语表

| 术语 | 含义 |
|---|---|
| **GSD** | Ground Sample Distance，地面采样距离 = 画面水平覆盖宽度 ÷ 图像水平像素数（mm/px） |
| **可判读性** | 目标实际尺寸 ÷ GSD ≥ **3 px** 才认为可靠 |
| **弃权 / 拒答（abstention）** | 系统判定"这张图下不了结论"时**主动拒绝**输出定量结论 |
| **`U` 级** | ★ **风险等级 `U` = 主动拒答**，**不是**"未检测到"。把 `U` 读成"没问题"是本项目最想避免的误报 |
| **A / B / C / D 级** | 依 GB 50010-2010 + JGJ 125-2016 的风险档 |
| **V3** | 当前数据集口径：**285 图 / 1646 实例 / 7 类**（唯一合法口径） |
| **7 类** | `crack` / `spalling` / `efflorescence` / `exposed_rebar` / `rust` / `delamination` / `moss` |
| **line_like / blob** | 测量算法两分支：线状（黑帽+骨架化，按宽度）vs 块状（局部对比度，按面积/直径） |
| **`clsbal`** | 类平衡损失实验（逆频率加权，`cls_pw=0.5`），把 45.6:1 长尾压到 6.75:1 |
| **`bfdd`** | 另一个公开数据集，用于跨域/红外对比实验 |
| **`conformal`** | 保形预测，用于给测量值配"带保证的区间" |
| **`change_detect`** | 变化检测模块（**不在产品链路上**，见 §4.1-12） |
| **`single_oom`** | 单图 OOD 兜底模块（**仅被脚手架引用**） |
| **`window_ok`** | 测量自检字段：尺寸是否落在可靠区间 ⇒ **默认 `True` 是已知隐患**（§6.3-2） |
