### ★ 宏平均（7 类等权）—— 长尾缓解的直接指标

- 对照: **0.7230**
- B1  : **0.7231**（+0.0001）
- B2  : **0.7099**（-0.0130）

> 为什么看宏平均：常规 mAP50 是**微平均**，被 rust 的绝对数量主导；降采样的目的正是让**稀有类**被看见，宏平均才对得上这个目的。

## 三、★ 限制条件（必须写进报告）

1. **固有混杂**：B1/B2 训练样本总量同时减少（1995 → 1425 / 1248），「AP 变化」不能单独归因于 rust 减少。
2. **val/test 未变**：两组的 val 与 test 均用 V3 正式集 ⇒ 口径与基线一致。
3. **唯一变量**：`cls_pw=0.0`（未启用类权重）、seed=42、其余超参同 COMMON_ARGS。
