# 如何把外墙缺陷筛查做得**更有挑战** —— 升级路径评估（2026-09-25）

> **起因**：赛题「我们鼓励什么」第 1 条要求「选择有挑战的方向，而不是"安全"的烂大街题目」。
> 本项目当前**属于红海方向**（YOLO + 裂缝/缺陷检测文献饱和，见 `先例与创造性核查_20260923.md`）。
> 本文回答：**在不推翻现有成果的前提下，走哪条路能让它真正"更有挑战"、且与赛题五大挑战点对齐。**
>
> **方法**：① 重读赛题五大赛道的「为什么有挑战」；② 盘点本项目**已具备**的能力（这是选路的前提，
> 不能从零开始）；③ 找出**项目自己留下的口子**（最可靠的起点）；④ 按「难度 / 与现有资产复用度 /
> 可验证性 / 风险」四维打分排序。

---

## 〇、先明确一条纪律：什么叫"更有挑战"

不是把题目换个花哨名字，而是满足**至少一条**：

| 挑战判据 | 含义 |
|---|---|
| **C1 不是调用 API 能一步完成的** | 需自行设计机制（赛题反复强调这点） |
| **C2 有硬约束下的取舍** | 如精度 vs 速度、覆盖率 vs 风险 |
| **C3 需要新的数据/标注设计** | 标注标准本身要自己定义 |
| **C4 有非循环、可证伪的验证** | 不能自己证明自己 |

> ⚠️ **反例（不要做）**：换更大的模型、堆更多数据、加注意力模块 ——
> 这些既不挑战、又会让已冻结的 V3 指标口径全部作废（需重训 + 重写全部报告）。

## 二、发现的两个**现成的升级契机**（数据自己说出来的）

### 契机 1：★ 类别极度不平衡，且**最安全关键的类恰是最少的**

实测（V3 全量 18286 实例）：

| 类别 | 实例数 | 占比 | 安全重要性 |
|---|---|---|---|
| `rust` 锈迹 | **13685** | 74.8% | 低（外观） |
| `exposed_rebar` 露筋 | 1389 | 7.6% | **极高**（结构） |
| `efflorescence` 泛碱 | 1152 | 6.3% | 低（渗水表征） |
| `delamination` 空鼓分层 | 694 | 3.8% | **高** |
| `moss` 苔藓 | 560 | 3.1% | 低 |
| `crack` 裂缝 | **469** | **2.57%** | **最高**（承载） |
| `spalling` 剥落 | **313** | **1.71%** | **高** |

- **不平衡度 max/min = 43.7 : 1**。
- 这**正是赛题赛道三（小样本与数据受限场景）**点名的形态：
  「长尾分布数据（正常样本 10000 张，异常样本 20 张）」。
- ⇒ **本项目天然就是一个长尾问题，但目前按"常规多类检测"处理，
  没有利用长尾这个特性做文章。**

### 契机 2：`rust` 74.8% 的占比**可能扭曲了模型的学习重心**

- `rust` 与 `crack` 在视觉上**共享"红褐色细长结构"特征**（锈迹和裂缝都可能是细的、暗的、带色）。
- ⇒ **可提出并检验一个假设**：「把 74.8% 的 rust 降采样/重加权后，crack 的 AP50 是否提升？」
- 这是一个**可证伪的实验**，且**不需要新数据**（现成数据重采样即可）。

## 三、五条升级路径（按推荐度排序）

### 【路 A】★★★ 把"选择性预测"从**单维几何**升级为**多维可学习的事前弃权**

| 项 | 内容 |
|---|---|
| **做什么** | 现在弃权信号 = 几何（GSD）+ 成像（质量），**都是手写的阈值**。升级：<br>① 把「几何 + 成像 + 模型置信度 + 目标类别」组合成一个**可学习的弃权器**（如 SelectiveNet 式的双头网络，或对现有多特征做逻辑回归/GBDT）；<br>② 用 **RC 曲线 + AUROC** 对比「手写几何判据 vs 学习式弃权器 vs 纯 softmax 置信度」三条基线；<br>③ **关键约束**：学习式弃权器必须**可解释**（输出"为什么弃权"的特征归因），否则违背赛道五 |
| **挑战性** | **C1 + C2** —— 不是调 API；且要处理"可学习 vs 可解释"的张力 |
| **与赛题对齐** | 赛道五（可解释性）+ 赛道三（长尾下的选择性预测） |
| **复用现有资产** | ★★★ 极高 —— RC 框架、合成真值、现有特征全在 |
| **可验证性** | ★★★ 高 —— RC 曲线/AUROC 是文献标准，评委能对照 |
| **成本** | 中（需训练一个轻量弃权头，不需重训主干） |
| **风险** | 中 —— 若学习式不如手写几何，**如实报告也是有价值的负结果** |
| **为什么有分量** | 文献里弃权信号几乎全是**模型不确定性**；本项目的**几何判据**是异类。**把两者在同一 RC 框架下正面对决**，是一个没人做过的干净实验 |

### 【路 B】★★★ 从"离线量化"升级为"**端侧实时**"（补上赛题赛道二的硬指标）

| 项 | 内容 |
|---|---|
| **做什么** | 现在量化只做到"体积 9.72 MB"（达标），但**明确声明不测延迟、不参赛道二**。<br>升级：① 把 INT8 混合精度模型搬到**真实端侧**（本机 CPU 或树莓派/手机）跑通端到端；<br>② 实测 **推理延迟 < 100 ms/帧** 这条硬指标（当前真实照片端到端 **5144 ms**，瓶颈是 OpenCV 的 `measure`）；<br>③ **挑战在于**：必须把 `_thin_skeleton` 的瓶颈解决掉（六轮试验已证明"不动语义就无解"）⇒ **要么改语义（重跑全部 mm 数字），要么用工程手段（异步/降采样/ROI 上限）** |
| **挑战性** | **C1 + C2** —— 精度-速度的硬取舍，且要在"不篡改已上报数字"的约束下做 |
| **与赛题对齐** | 赛道二（极端资源约束部署）—— 本项目**尚未真正达标**（延迟未测） |
| **复用现有资产** | ★★ 中 —— 量化产物已有，但延迟优化要动 `measure.py` |
| **可验证性** | ★★★ 高 —— <100ms 是明确的数字判据 |
| **成本** | **高**（最大风险项） |
| **风险** | **高** —— 动 `_thin_skeleton` 会改变已上报的毫米数字 ⇒ 需全链路回归 + 重跑所有 mm 结论 |
| **为什么有分量** | 这是**赛题明文给了硬指标的赛道**，达标与否一目了然。**但目前做的"量化"只到体积层，没到速度层** |

### 【路 C】★★ 把"拒答"升级为"**可执行的采集闭环**"（人机交互做实）

| 项 | 内容 |
|---|---|
| **做什么** | 现在拒答只说"判不了"。升级为**闭环**：<br>① **反解物理约束**：告诉用户"要判 0.3mm 裂缝须 GSD ≤ 0.1mm/px ⇒ 用 24mm 主摄靠近到 0.27 m"；<br>② **闭环验证**：收集站上传→系统判"不合格并给距离建议"→用户重拍→**再次上传**→系统判"合格" —— **端到端闭环有数据留痕**；<br>③ 把这条闭环的**用户行为日志**（重拍了几次、距离是否真的改了）做成可用性证据 |
| **挑战性** | **C1 + C3** —— 定义"合格采集"的标准本身是设计工作；需要真实用户行为数据 |
| **与赛题对齐** | 赛道五（人机交互：允许人类干预决策逻辑） |
| **复用现有资产** | ★★★ 极高 —— GSD 反解是简单公式，收集站已在线 |
| **可验证性** | ★★ 中 —— 需真实投稿（**当前投稿 0 条**，是硬伤） |
| **成本** | **低**（改 app.py + 收集站前端） |
| **风险** | 低，但**依赖能否拉到真实用户**（可找同学/群友配合） |
| **为什么有分量** | 文献多在讲"能不能测"，**很少讲"测不到时该退到多远重拍"** —— 这是把逆问题做成产品功能 |

### 【路 D】★★ 用**长尾重加权**做一次**可证伪的模型诊断实验**（契机 2 落地）

| 项 | 内容 |
|---|---|
| **做什么** | 提出并检验：「`rust` 占 74.8% 是否挤占了 `crack`/`spalling` 的学习容量？」<br>① 对照组：现状（不重加权）；<br>② 实验组 A：按类别频率**逆频率重加权**（已做过 clsbal，可复用）；<br>③ 实验组 B：**rust 降采样**到与 crack 同量级；<br>④ 指标：7 类逐类 AP50 + 宏平均（而非只看 mAP50） |
| **挑战性** | **C4** —— 干净的对照实验，结论可证伪 |
| **与赛题对齐** | 赛道三（长尾分布） |
| **复用现有资产** | ★★★ 高 —— clsbal 实验框架已有（`v11s640_clsbal`），加一档降采样即可 |
| **可验证性** | ★★★ 高 —— 逐类 AP 是硬数字 |
| **成本** | 中（需重训 1~2 组，约 30 分钟/组） |
| **风险** | 中 —— 若结论是"重加权无改善"，**如实报告仍是有效结论**（且能反驳"堆数据能解决"的朴素观点） |
| **为什么有分量** | 它把本项目**与生俱来的数据缺陷**转成**主动的研究问题**，而不是藏着 |

### 【路 E】★ 多距离/多视角联合判读（**不建议现在做**）

- 属赛道四（多视图几何），**会跳出赛道五**；且需新增采集与实验，成本高。
- 前次评估（`创新方向评估_20260923.md` §四）已判定"不建议"，**维持该结论**。

## 四、推荐组合（按"性价比 × 挑战性"）

| 优先 | 路径 | 挑战维度 | 成本 | 是否动 GPU | 是否改已上报数字 | 建议 |
|---|---|---|---|---|---|---|
| **1** | **A** 学习式弃权器 vs 几何判据对决 | C1+C2 | 中 | 否 | **否** | **最该做** —— 唯一能造出"别人没有的对照实验"的路 |
| **2** | **D** 长尾重加权诊断 | C4 | 中 | 是（1~2 组） | 否 | 顺手做 —— 把数据缺陷转成研究问题，且框架已有 |
| **3** | **C** 采集闭环 | C1+C3 | 低 | 否 | 否 | 低垂果实，但需真实用户配合 |
| **4** | **B** 端侧实时 | C1+C2 | **高** | 否 | **是 ⚠️** | 挑战性最高，但**动 measure 会作废全部 mm 数字**，需谨慎评估 |

### 一条"叙事最完整"的升级主张（A + D 组合）

> 「我们把外墙筛查做成一个**知道自己什么时候不可靠**的系统。
> 弃权通常靠模型的不确定性（softmax/能量），而我们用的是**几何判据** ——
> 目标实际尺寸 ÷ GSD。我们把它和**学习式弃权器、纯置信度阈值**放进**同一套
> risk–coverage 框架**正面对决，画出了三条曲线。
> 同时我们发现自己的数据是 **43.7:1 的长尾**（最关键的裂缝只占 2.57%），
> 于是做了重加权诊断实验 —— **不是掩盖这个缺陷，而是把它变成一个可证伪的问题。**」

⇒ 这条主张同时命中**赛道五（可解释性）+ 赛道三（长尾）**，
且**每一句都有曲线或数字支撑**，全部可复算。

## 五、⚠️ 必须避免的"假挑战"（会适得其反）

| 假挑战 | 为什么是假的 |
|---|---|
| 换更大模型 / 加注意力模块 | 堆算力 ≠ 挑战；且会作废 V3 指标口径 |
| 换赛道到赛道一（时序） | 外墙筛查是**单图任务**，无时序维度，硬套会被问穿 |
| 声称"首次" | 先例核查已证明 6 条都能找到先例（见 `先例与创造性核查_20260923.md`） |
| 只提高指标口径（如报 mAP50-95 更好看） | 是修饰不是挑战 |

## 七、结论

**「更有挑战」的最优解不是换题目，而是把已经跨进去的赛道五推到更深处，
同时吃下赛道三（长尾）这个项目与生俱来、却一直没被利用的特性。**

- **最小且最有力的动作** = 路 A（学习式弃权器 × RC 对决）+ 路 D（长尾诊断）。
- 两者**都不动已上报的毫米数字、不换赛道**，却能造出**文献里没有的对照实验**。
- **路 B（端侧实时）挑战性最高，但风险也最高**（动 `measure` ⇒ 全链路回归），需单独评估。
