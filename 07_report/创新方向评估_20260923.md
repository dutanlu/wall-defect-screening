## 二、★ 四个可创新方向（**全部符合赛道五**）

### 方向 A：**把「拒答」从主张变成可测量的 risk–coverage 曲线** ← 最有分量

| 项 | 内容 |
|---|---|
| **做什么** | 完成技术报告 §7.4B 自留的那一步：对测试集逐实例统计 **coverage（被接受的比例）** 与 **selective risk（被接受实例上的误差）**，画出 **risk–coverage 曲线**，并对比"几何拒答 vs 不拒答" |
| **为什么有分量** | ① **risk–coverage 是选择性预测领域的标准评估语言**（Chow 1957 → Geifman 2017 一脉）⇒ 用它讲话，评审立刻能定位我们的工作；② 我们的弃权信号是**几何的、非概率的**，而文献几乎全用不确定性 —— **在同一套评估框架下比出差异**，这才是能站住的方法层贡献；③ 它把「我们做得对」从**主张**变成**可测量的曲线** |
| **赛道契合** | ✅ **赛道五**：可解释性如果不可评估，就只是宣称。做了它，我们的「可解释」变成**可验证**的 |
| **成本** | 中。需要：逐实例的「可判读/不可判读」判定（已有 `assess_interpretability`）+ 逐实例误差（借 §7.6 的**合成真值**框架）。**不需要重训、不需要 GPU** |
| **证据要求** | 一张 RC 曲线图 + coverage/risk 数值表 + 与"纯置信度阈值弃权"的对照 |
| **风险** | 低。即使曲线不好看，**如实报告也是合格的实验结果** |

### 方向 B：**把「图像质量」并入可判读性 —— 从"几何合格"到"成像合格"** ← 叙事最好

| 项 | 内容 |
|---|---|
| **做什么** | 现在系统只看 GSD（几何）就判"可判读"。但**我们自己实测发现**：低照度下 mAP 仅 0.159 —— 即**几何合格但图像不可用**。补上：定义客观图像质量指标（亮度 / 对比度 / 清晰度 / 噪声），与几何判据**并列**纳入拒答 |
| **为什么有分量** | ① 这是**用我们自己的实验结果驱动的改进**，叙事闭环完美（"我们做了鲁棒性实验 → 发现了一个真实漏洞 → 补上它"）；② 它让"可判读性"从**单因（GSD）**升级为**双因（几何 × 成像）**，概念上更完备；③ **主动暴露并修补自己的漏洞**，是评审最认可的科研态度 |
| **赛道契合** | ✅ **赛道五**：拒答机制更完备 = 可解释性更强；而且能讲成"系统知道自己**两种**不知道" |
| **成本** | 中。需 ① 从现有鲁棒性实验数据里定指标与阈值；② 改 `gsd.py`/`app.py` 的判定逻辑；③ 补一节实验 |
| **证据要求** | 低照度/模糊/噪声三档下，"几何合格率 vs 实际可用率"的对照表（**现有数据就能算，不必新采**） |
| **风险** | 低。且**即使指标定得不完美，如实报告也是有效结论** |

### 方向 C：**把「拒答」变成可执行的采集指引**（反解物理约束）← 低垂果实

| 项 | 内容 |
|---|---|
| **做什么** | 现在拒答只说"判不了"。改成**告诉用户怎么办**：<br>「要判读 0.3mm 裂缝需 GSD ≤ 0.1mm/px ⇒ 用等效 24mm 主摄须靠近到 **0.27 m**；或换 5x 长焦到 **1.3 m**；或在画面里放一把尺子（标定物法）」 |
| **为什么有分量** | ① 这是把物理约束的**逆问题**做成产品功能 —— 文献多在讲"能不能测"，**很少讲"测不到时该退到多远重拍"**；② 它把"拒答"从**终点**变成**下一步动作的起点**，这正是**人机交互**的实质；③ 直接回应我们"拍摄端空白 + 收集站 0 投稿"这个业务缺口 |
| **赛道契合** | ✅ **赛道五（人机交互）** —— 属于赛题原文赛道五说的「**允许人类干预决策逻辑的交互式系统**」 |
| **成本** | **低**。GSD 反解是简单公式（`距离 = 像素数 × 真实尺寸 / (像素数×...)`），输入与阈值都已有 |
| **证据要求** | 界面截图（拒答时给出具体距离/焦距建议）+ 一节说明 |
| **风险** | 很低。**改 `app.py` ⇒ 需重录演示视频**（已挂 task #69，可合并一次做完） |

### 方向 D：**实例级可判读性可视化**（每个检测框自带可解释标注）

| 项 | 内容 |
|---|---|
| **做什么** | 标注图上**每个框旁标注**：该类目标的图上像素数 + 「可判读 / 不可判读」标记（如 `裂缝 0.6px ✗` / `泛碱 20.0px ✓`） |
| **为什么有分量** | 让**可视化本身承载可解释性** —— 评委一眼就能看出"哪些框可信、哪些只是存在性提示"，无需读文字 |
| **赛道契合** | ✅ **赛道五**（可解释性的可视化呈现）；也顺带补强基础分「可视化呈现 5 分」 |
| **成本** | **低**。数据已在 payload 里（`capability` + 每实例类别），只需改绘图函数 |
| **风险** | 极低。同为 `app.py` 改动，**与方向 C 合并一次重录视频** |

## 三、四个方向的优先级建议

| 顺序 | 方向 | 分量 | 成本 | 是否动 GPU | 建议 |
|---|---|---|---|---|---|
| **1** | **A** risk–coverage 曲线 | ★★★ | 中 | 否 | **最该做** —— 它把我们最独特的机制用文献标准语言量化 |
| **2** | **B** 图像质量并入拒答 | ★★★ | 中 | 否 | **叙事最好** —— 用自己的实验发现驱动改进 |
| **3** | **C** 采集指引 | ★★ | 低 | 否 | 低垂果实，HCI 强，顺手做 |
| **4** | **D** 实例级可视化 | ★★ | 低 | 否 | 顺手做，与 C 合并重录视频 |

**A+B 合起来能形成一条完整的新主张**：

> 「我们的弃答判据有二：**几何够不够（GSD）+ 成像够不够（质量）**。
> 并且我们**用 risk–coverage 曲线证明了**：拒答确实把误差从被拒绝的那部分移走了 ——
> 这不是我们说的，是**实测曲线**说的。」

⇒ 这句话同时补上 §7.4B 的自留项与 §7.3 的发现，**且全程不需重训**（不受现有训练中断影响）。

## 四、⚠️ 两个会「跳出赛道五」的方向（不建议做）

| 方向 | 为什么跳出 |
|---|---|
| **多距离 / 多视角联合判读** | 属**方法层**贡献（多视图几何），契合的是**赛道四（多模态与跨域融合）**，不是赛道五。且需新增采集与实验，成本高 |
| **缺陷时序演化对比**（同一栋楼多次巡检） | 契合的是**赛道一（行为理解与时序分析）**。且需多次巡检数据 —— 我们收集站**投稿 0 条**，无数据基础 |

> ⚠️ 提醒：用户此前问过「走第一赛道行不行」。**外墙筛查是单图任务，没有时序维度，不属于赛道一**
> （详见此前答复）。本节两个方向若要做，等于**换赛道**，会牵动全部材料的定位口径 —— 不建议。

## 五、赛道契合度总判断

四个建议方向**全部在赛道五内**，且分别补强赛道五的不同侧面：

| 方向 | 补强赛道五的哪一面 |
|---|---|
| A | **可解释性要可评估**（否则只是宣称） |
| B | **拒答要完备**（系统知道自己"两种不知道"） |
| C | **人机交互**：拒答 → 指导人重新采集 |
| D | **可解释的可视化呈现** |

⇒ **不需要换赛道。** 相反，做完 A~D，赛道五的契合度会比现在**实质提升**
（因为赛道五的官方技术挑战里，「人机交互界面设计」与「可解释性」我们都从"有"变成"有且可验证"）。
